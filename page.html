How this comparison works

A fixed, stratified 70/30 split separates training and test records. Three-fold cross-validation uses only the training partition. Probabilities ≥ 50% predict “Yes”. Logistic regression uses standardised inputs, an intercept and L2 regularisation, without interaction terms.

The original Enrolled label contains thresholds and interactions designed to favour random forest with the relevant features and enough depth. Other label choices define different tasks and may favour either model. A sparse feature selection or shallow forest may not beat logistic regression. Scores are calculated, never forced.

These are custom teaching implementations, not production modelling software. Repeatedly tuning against the test scores makes the test set less independent.
